# Publicación rápida en GitHub Pages

1. Crear un repositorio llamado `guialab-pedidos`.
2. Subir a la raíz del repositorio todos los archivos y carpetas de este paquete.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar **main** y **/(root)**; guardar.
6. Esperar el enlace publicado que GitHub mostrará en esa misma pantalla.

No subir la carpeta contenedora: `index.html` debe quedar directamente en la raíz del repositorio.

Para actualizar el sitio, subir los archivos modificados y confirmar el cambio en `main`.

Si el repositorio se mantiene público, cualquier archivo que se suba allí podrá ser descargado. No incluir datos personales, fotografías de pedidos reales ni secretos.
